# UI Redesign Report

Дата: 2026-06-27

Цель: упростить frontend Tuda Suda, привести интерфейс к premium mobile-first Telegram Mini App стилю и не менять backend без необходимости.

## 1. Какие файлы изменены

- `frontend/src/App.jsx`
- `frontend/src/api.js`
- `frontend/src/styles.css`
- `frontend/package-lock.json`
- `UI_REDESIGN_REPORT.md`

Также удалены локальные frontend-артефакты:

- `frontend/.DS_Store`
- `frontend/package-lock 2.json`

## 2. Как изменилась навигация

Нижняя навигация упрощена до трех вкладок:

- `Главная`
- `Все`
- `Профиль`

Навигация стала короткой, mobile-first и понятной для MVP.

## 3. Какие вкладки удалены или перенесены

Удалены из нижней навигации:

- `Дар`
- `История`
- `Топ`
- `TON`
- `Актив`
- старый dev/admin `Ledger` как отдельная сложная вкладка

Компоненты не удалялись агрессивно, чтобы не рисковать рабочей логикой, но они больше не доступны через основную навигацию.

## 4. Как реализована liquid glass тема

В `frontend/src/styles.css` полностью заменена визуальная система:

- темный мягкий градиентный фон;
- glass-card блоки с прозрачностью;
- `backdrop-filter: blur(...)`;
- мягкие тени;
- крупные скругления;
- спокойные акценты: бирюзовый, фиолетовый, теплый золотой для кармы;
- зеленый для успешных операций;
- мягкий красный для ошибок;
- плавные состояния кнопок и сегментов;
- адаптация под узкий мобильный экран.

В browser-code не добавлялись Node-only polyfills, `Buffer`, `process` или `global`.

## 5. Где теперь находится отправка дара

Отправка дара находится на вкладке `Главная`.

На главной есть основной CTA:

- `Отправить дар`

По нажатию раскрывается форма отправки:

- виртуальные монеты;
- asset-подарки через TON/TDSD;
- выбор токена;
- сумма;
- анонимное сообщение.

Существующие API для отправки не менялись.

## 6. Где теперь находится история

История больше не является отдельной нижней вкладкой.

На `Главной` есть блок:

- `Последние операции`

Он показывает последние операции пользователя в компактном виде.

Вкладка `Все` показывает простую mobile-friendly ленту транзакций без фильтров:

- дата;
- пользователь;
- тип операции;
- токен;
- сумма;
- направление;
- комментарий.

Если включен admin ledger, используется общий ledger. Если admin ledger недоступен, экран показывает публичную ленту asset-gifts и операции текущего пользователя.

## 7. Где теперь находится TON/TDSD

TON/TDSD полностью перенесены в `Профиль`.

В профиле теперь находятся:

- данные пользователя;
- карма;
- репутация;
- сохраненный TON wallet;
- TON Connect статус;
- балансы TON/TDSD;
- действия подключения/сохранения/отключения кошелька;
- создание TON/TDSD deposit;
- список депозитов;
- mock-user block для локального тестирования, если mock mode включен.

TON Connect logic не менялась.

## 8. Как проверить приложение локально

Backend:

```bash
cd tuda-suda/backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python seed.py
uvicorn app.main:app --reload
```

Frontend:

```bash
cd tuda-suda/frontend
npm install
npm run build
npm run dev
```

Проверить в браузере:

```text
http://localhost:5173
```

Что проверить руками:

- приложение открывается без белого экрана;
- нижняя навигация содержит только `Главная`, `Все`, `Профиль`;
- на главной раскрывается форма `Отправить дар`;
- asset gift работает для TON/TDSD;
- последние операции отображаются на главной;
- `Все` показывает простой список операций без фильтров;
- в профиле подключается и сохраняется TON wallet;
- балансы TON/TDSD отображаются в профиле;
- deposit flow не сломан.

## 9. Выполненные проверки

Успешно:

```bash
cd tuda-suda/frontend
npm install
npm run build
```

`npm run build` прошел без ошибок.

Проверено:

- прямой импорт `@ton/core` во frontend source отсутствует;
- ошибка `Buffer is not defined` не возвращена через source-код;
- `@tonconnect/ui-react` остался единственной TON Connect frontend-зависимостью.

Ограничение среды Codex:

```bash
npm run dev -- --host 127.0.0.1 --port 5173
```

не смог открыть порт из-за sandbox-ошибки:

```text
listen EPERM: operation not permitted 127.0.0.1:5173
```

Это ограничение среды, не ошибка frontend build. Локально в VS Code команду нужно проверить обычным способом.
