## 3. Показывает ли вкладка «Все транзакции» все операции всех пользователей

Да. Раньше вкладка в обычном режиме могла показывать смесь публичной ленты asset-gifts и операций текущего пользователя. Полный общий ledger был доступен только через admin endpoint.

Теперь вкладка `Все` использует новый публичный endpoint:

```text
GET /transactions/public
```

Он возвращает единый список операций проекта независимо от текущего пользователя:

- виртуальные подарки всех пользователей;
- completed asset-подарки всех пользователей.

Каждая запись содержит:

- дату и время;
- отправителя;
- получателя;
- токен;
- сумму;
- направление операции;
- комментарий, если он есть.

Фильтры не добавлялись.

## 4. Изменения backend

Backend был изменен минимально, потому что существующего публичного endpoint для всех транзакций всех пользователей не было.

Добавлено:

- schema `PublicTransactionFeedItem`;
- serializer для виртуальных подарков;
- serializer для asset-подарков;
- endpoint `GET /transactions/public`.

Существующие endpoints и логика авторизации, TON Connect, TON/TDSD, подарков, истории пользователя и admin ledger не менялись.
